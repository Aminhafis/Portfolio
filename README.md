# Developer Portfolio — Amin Hafis

Personal developer portfolio detailing full-stack web applications, technical background, and coursework as an Applied Informatics student at Hochschule Weihenstephan-Triesdorf (HSWT).

---

## Overview

- Highlights full-stack projects: **Am Bookstore**, **Travel Support RAG**, and **Highway Delite**.

- Responsive layout across desktop and mobile devices.

- **Styling:** Tailwind CSS / CSS3
- **Deployment:** Vercel
